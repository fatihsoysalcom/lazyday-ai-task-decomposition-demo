# LazyDay AI Task Decomposition Demo

This example demonstrates the core principles of the 'LazyDay AI' productivity approach: breaking down large, daunting tasks into small, manageable 'micro-tasks' to reduce overthinking and foster incremental progress. It simulates an AI-like system that helps decompose a project and celebrates the completion of each tiny step, reinforcing the idea of achieving sustainable success through small wins.

## Language

`python`

## How to Run

Save the code as `lazyday_ai_productivity.py`.
Run from your terminal: `python lazyday_ai_productivity.py`
